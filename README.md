# MyToDo2 2.0.1

바탕화면 말풍선에서 메모와 일정을 확인하고 편집하는 Windows용 무료 위젯입니다. 로컬에서 바로 사용하거나 개인 Google 시트를 연결해 여러 PC에서 이어 사용할 수 있습니다.

## 시작하기

기존 프로그램이 실행 중이면 종료한 뒤 Windows x64용 배포 ZIP 전체를 풀고 `MyToDo2.exe`를 실행합니다. 자체 포함 배포본은 .NET을 따로 설치하지 않아도 됩니다. 연결 전 메모와 일정은 현재 PC에 저장합니다.

1. 상단 **M**은 메모, **S**는 일정입니다. **＋ / Ctrl+N**으로 추가합니다.
2. 말풍선을 **더블클릭**하거나 연필 아이콘을 눌러 편집합니다.
3. 항목 화살표는 **1줄 → 2줄 → 전체**, 상단 화살표는 위젯 전체 접기·펼치기입니다.
4. 다른 PC에서도 사용하려면 **우클릭 → 설정 → 시트 연결**의 네 단계를 진행하고 같은 전용 코드를 등록합니다.

## 주요 기능

- 자유로운 메모와 날짜·시각을 표시하는 일정
- 완료·취소와 위젯에서 숨기기: 연결된 시트에는 보관
- 말풍선 드래그 순서 변경과 PC 간 순서 공유
- 본문·해시태그 검색, 항목별 색상과 임박 일정 강조
- 말풍선 모양·꼬리·색상·글꼴·불투명도 설정
- 내용에 맞춰 늘고 줄어드는 위젯 높이, 가로 폭 조절
- 편집 저장 후 자동 전송, 실행 직후 1회 조회, 기본 30분 정기 동기화, F5 수동 동기화
- JSON 백업·가져오기, CSV 저장, Windows 시작 시 자동 실행

개인 시트의 공유 설정은 **제한됨**으로 유지합니다. 전용 코드를 가진 사람은 메모에 접근할 수 있으므로 코드를 공개하지 마세요. 연결정보는 JSON 백업에 포함하지 않습니다.

## 소스에서 빌드하기

[Visual Studio 빌드 안내](docs/BUILD.md)를 따르세요. 저장소 이름과 솔루션 파일은 `MyToDoWidget`, 프로그램의 정식 명칭과 실행 파일은 **MyToDo2 / MyToDo2.exe**입니다. 태그는 **2.0.1**이며 접두사 v를 붙이지 않습니다.

Windows에서 `build_release.bat`을 실행하면 자체 포함 배포 ZIP과 SHA-256 체크섬(`.zip.sha256`)을 한 번에 생성합니다. .NET 10 SDK가 필요하며, 결과는 `dist/`에 저장합니다.

설치용 Apps Script는 `apps-script/MyToDoSetup.gs` 한 파일로 공개하고 프로그램에도 내장합니다. 사용자는 자신의 새 Google 시트에서 한 번 붙여넣고 실행한 뒤, 단계별 안내에 따라 권한 승인·웹 앱 배포·전용 코드 연결을 진행합니다. 개발자의 Google Drive 원본이나 템플릿 연결 페이지를 이용하지 않습니다. 제3자도 주소 설정 없이 같은 소스를 빌드할 수 있습니다.

`TemplateSource*.json`은 프로그램에서 읽지 않고 빌드·게시·실행용 ZIP에서도 제외합니다. 실제 사용자 시트·배포 주소·전용 코드·메모는 공개 소스에 포함하지 않습니다.

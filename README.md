# MyToDo 1.1.2

Google Sheets의 자유 메모를 바탕화면의 말풍선으로 읽는 Windows 위젯입니다.
메모는 구글 시트에서 작성하고, 위젯의 **새로고침** 한 번으로 확인합니다.

- 제작: **MathTime**
- 공식 배포 페이지: https://mathtime.kr/?page=mytodo
- GitHub: https://github.com/lottoria-dev/MyToDoWidget
- 소스 라이선스: [MIT](LICENSE.md)
- 개발 환경: C# / .NET 10 / WPF
- 배포 대상: Windows x64 · 런타임 포함 단일 EXE

## 주요 기능

- A1부터 A열의 비어 있지 않은 셀을 순서대로 표시합니다. 셀 하나가 메모 하나이며 제목 행은 없습니다.
- 줄바꿈·한글·기호를 유지합니다. 날짜와 todo/done은 자유로운 일반 텍스트입니다.
- 말풍선 정렬(왼쪽·가운데·오른쪽), 가로 폭(내용·위젯 폭), 수직 간격(0~40)을 설정합니다.
- 5가지 말풍선 모양, 꼬리 방향, 12가지 파스텔 테마와 사용자 지정 배경·글자색을 제공합니다.
- 한글 고정폭 추천 글꼴, 글자 크기·굵게·기울임, 위젯 크기에 따른 글자 확대·축소를 지원합니다.
- 유리판 8가지 테마와 사용자 색상, 말풍선·유리판·상단바·흰색 테두리 불투명도를 각각 조절합니다.
- 상단바에 갱신 시각·새로고침·접기/펼치기·최소화·▲▼를 모았습니다. 메모는 휠로도 읽습니다.
- 설정과 구글 시트 열기는 우클릭 메뉴에서 사용합니다. 말풍선 더블클릭도 구글 시트 목록을 엽니다.
- 화면 잠금·절전 복귀 시 저장 위치 복원을 시도하고, 트레이에서 주 모니터로 가져올 수 있습니다.
- 환경설정창은 밝은 테마로 고정하며, 위젯 색상과 별도로 표시합니다.
- 간편 설정 및 사용법 탭, CSV 템플릿 저장, 정보 탭을 제공합니다.
- Windows 시작 시 자동 실행을 선택할 수 있습니다. 현재 Windows 계정에 적용되며 기본값은 꺼짐입니다.

위젯은 공유된 시트의 CSV를 읽는 도구입니다. 시트 수정·업로드, 날짜 자동 정렬, 완료 상태 관리, 주기적인 자동 동기화는 수행하지 않습니다.

## 구글 시트 연결

**민감한 메모는 입력하지 않는 것을 권장합니다. 뷰어는 수정을 막지만, 링크를 아는 사람은 로그인 없이 내용을 읽을 수 있습니다.**

1. https://docs.google.com/spreadsheets/ 에서 메모 전용 스프레드시트 파일을 만듭니다.
2. `templates/MyToDo_Template.csv`를 가져오거나 A1부터 메모를 입력합니다. **간편 설정 및 사용법 → CSV 템플릿 저장**에서도 예시를 꺼낼 수 있습니다.
3. A열을 일반 텍스트로 지정합니다. 셀 하나가 메모 하나이며 셀 안 줄바꿈은 `Alt+Enter`입니다.
4. 오른쪽 위 **공유 → 일반 액세스 → 링크가 있는 모든 사용자 → 뷰어**를 선택하고 완료합니다.
5. 메모를 적은 탭을 열고 브라우저 주소를 복사합니다. 일반 공유 링크도 사용할 수 있으며 탭 번호가 없으면 첫 탭을 읽습니다.
6. 위젯 **우클릭 → 설정 → 연결·동작**에 주소를 붙여넣고 저장합니다.
7. 수정 후 **새로고침** 또는 `F5`를 누릅니다. 다른 PC에도 같은 주소를 처음 한 번 등록합니다.

‘웹에 게시’는 필요하지 않습니다. OAuth 클라이언트·API 키·Google 계정 로그인 없이 읽습니다.
시트 편집에 필요한 로그인은 브라우저에서 관리합니다. 위젯은 로그인 정보를 가져오지 않습니다.
공유 권한은 파일 전체에 적용됩니다. A열만 위젯에 표시해도 다른 열·탭의 열람이 차단되지는 않습니다.
파일 소유자의 이름·이메일도 표시될 수 있습니다. 개인정보가 들어 있는 기존 파일을 그대로 공유하지 마세요.

연결 화면과 사용법 탭에서도 같은 경고를 표시합니다. 전체 처리 정책은 [DATA_HANDLING.md](docs/DATA_HANDLING.md)를 확인하세요.

## 기본 조작

| 조작 | 동작 |
|---|---|
| 상단 제목·빈 곳 끌기 | 위젯 이동; 이동 중 Esc로 취소 |
| 펼친 위젯 가장자리·모서리 끌기 | 크기 조절 |
| 휠 / 상단 ▲▼ | 메모 스크롤 |
| 새로고침 / F5 | 공유된 메모 다시 읽기 |
| 우클릭 → 설정 | 꾸미기·연결·동작 설정 |
| 말풍선 더블클릭 / 우클릭 → 구글 시트 열기 | 구글 시트 목록 열기 |
| 접기·펼치기 | 본문 접기 또는 이전 높이·스크롤 복원 |
| 최소화 / Alt+F4 | 트레이로 숨기기 |
| 메모 선택 후 Ctrl+C | 선택한 메모 복사 |
| 트레이 더블클릭 / 트레이 → 종료 | 다시 표시 / 완전 종료 |
| 트레이 → 주 모니터로 가져오기 | 화면 밖 위젯 복구 |

불투명도는 0% 완전 투명, 100% 완전 불투명입니다. 글자는 배경 불투명도의 영향을 받지 않습니다.
배경이 완전히 투명한 빈 곳은 아래 창으로 입력이 전달될 수 있으므로 ▲▼ 또는 글자 위의 휠을 사용하세요.
위젯은 일반 독립 창입니다.

## Windows 시작 시 자동 실행

1. 위젯 **우클릭 → 설정 → 연결·동작**을 엽니다.
2. **Windows 시작 시 자동 실행**을 켜고 **저장**합니다. 현재 Windows 계정으로 로그인할 때 위젯이 열립니다.
3. 최신 메모도 불러오려면 **실행할 때 한 번 새로고침**을 함께 선택합니다. 두 옵션은 서로 독립적입니다.

처음에는 꺼져 있습니다. 체크만 바꾸고 취소하면 등록은 변경되지 않습니다. 끄고 저장하면 등록을 해제합니다.
EXE를 다른 폴더로 옮겼다면 새 위치에서 한 번 직접 실행하세요. 기존 등록이 있을 때만 경로를 갱신합니다.
앱을 삭제하기 전 자동 실행을 끄세요. Windows의 **설정 → 앱 → 시작 프로그램** 또는 작업 관리자에서 MyToDo를 차단한 경우 그곳에서도 사용으로 바꿔야 합니다.
Windows가 자동 실행을 지연할 수 있으며, 이 옵션은 전원 켜짐 직후가 아닌 사용자 로그인 시 동작합니다.

자동 실행 등록은 사용자별 Windows Run 항목에 저장합니다. 메모 설정의 백업을 복원해도 해제한 자동 실행을 다시 켜지 않습니다.
관리자 권한은 요구하지 않으며, 등록 또는 설정 저장에 실패하면 오류를 알리고 가능한 경우 이전 등록을 복원합니다.

## Visual Studio 빌드

이 묶음은 **1.1.2 정식 릴리즈용 소스**입니다. 실행 파일·DLL·bin/obj·개인 설정을 포함하지 않습니다.
.NET 10을 지원하는 Visual Studio와 **.NET 데스크톱 개발** 워크로드를 준비합니다.

1. `MyToDoWidget.sln`을 엽니다.
2. `MyToDoWidget`을 시작 프로젝트로 지정합니다.
3. `Release` 구성으로 빌드한 뒤 `F5` 또는 `Ctrl+F5`로 실행합니다.
4. [Windows 확인 순서](docs/TESTING_KO.md)를 따라 연결·화면·자동 실행을 확인합니다.

기본 `MyToDoTestBuild=false`는 정식판 설정·인스턴스·자동 실행 등록을 사용합니다.
기존 정식판을 트레이에서 완전히 종료한 뒤 실행하세요.
이전 검토용 빌드의 `%LOCALAPPDATA%\MyToDoWidget.Test` 설정은 자동으로 가져오지 않습니다.
검토용에서 옮기는 경우 구글 시트에서 공유 주소를 다시 복사하여 등록하세요.

배포는 프로젝트 **게시 → Standalone-win-x64** 프로필을 사용합니다.
런타임을 포함한 Windows x64 단일 EXE를 `dist/MyToDoWidget-1.1.2-win-x64/`에 만듭니다.
사용자는 .NET을 별도로 설치하지 않아도 됩니다. 네이티브 구성요소는 실행할 때 임시 폴더에 풀릴 수 있습니다.

사용 안내·템플릿·라이선스가 포함된 ZIP과 SHA-256 파일은 Windows에서 `build_release.bat`로 생성합니다.
이 스크립트는 정식판으로 게시하며 일반 솔루션 빌드에서 자동 실행되지 않습니다.
이번 소스 생성 과정에서는 실행 파일을 만들거나 게시 스크립트를 실행하지 않았습니다.

개발 중 기존 정식판과 분리할 때만 `-p:MyToDoTestBuild=true`를 지정하세요.
이 선택은 별도 설정 폴더·인스턴스·자동 실행 등록과 정보 탭의 검토용 표기를 사용합니다.
배포용 게시 프로필과 `build_release.bat`는 정식판 설정을 명시합니다.

## 검증

핵심 로직 확인은 Windows 개발 환경에서 `run_checks.bat` 또는 다음 명령으로 실행합니다.

```text
dotnet run --project tests/MyToDoWidget.Checks -c Release -- templates/MyToDo_Template.csv
```

화면·DPI·트레이·잠금/절전 복귀는 실제 Windows 환경에서 확인해야 합니다.

## 업데이트와 데이터

- 기본 정식판 설정: `%LOCALAPPDATA%\MyToDoWidget\state.dat`
- 선택적 검토용 설정: `%LOCALAPPDATA%\MyToDoWidget.Test\state.dat`
- 설정·연결 주소·마지막 메모를 Windows 사용자 계정으로 암호화하고 이전 정상 상태의 백업을 보관합니다.
- 저장된 주소는 화면에 다시 표시하거나 복사·내보내지 않습니다. 등록 여부만 표시합니다.
- 구글 시트 열기는 항상 시트 목록을 엽니다. 연결 주소를 브라우저로 전달하지 않습니다.
- 연결 실패 시 마지막 정상 메모와 갱신 시각을 유지합니다. 정상적으로 빈 A열을 받으면 목록을 비웁니다.
- 메모 표시 순서는 A열 순서이며 다른 열과 시트의 글꼴·색상 서식은 표시하지 않습니다.
- 정식 설정 이전 시 예전 ‘웹에 게시’ 주소는 연결·캐시를 해제하고 일반 공유 주소 등록을 안내합니다. 외형 설정은 유지합니다.
- 위젯의 연결 변경·해제는 Google 공유 권한을 바꾸지 않습니다. 기존 게시본은 Google에서 별도로 게시를 중지해야 합니다.

OAuth 시험본 1.1.0은 이번 1.x 정책에 채택하지 않았습니다.
Apps Script는 이후 주요 업데이트의 계획입니다. [ROADMAP.md](ROADMAP.md)에 구현 단계와 보호 한계를 기록했습니다.

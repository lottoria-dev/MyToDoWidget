# MyToDo Widget 0.3.0

Google Sheets의 A열에 적어 둔 자유 메모를 Windows 위젯에서 읽습니다.
메모 입력과 수정은 Google Sheets에서 하고, 위젯에서는 **새로고침** 한 번으로 확인합니다.

## 0.3.0 화면과 꾸미기

- 상단 제목 표시줄 높이 **24**, 하단 상태 표시줄 높이 **20**으로 1.2배 비율을 적용했습니다. Windows 화면 배율에 따라 함께 확대됩니다.
- 상단에는 **새로고침 / 구글 시트 / 설정 / 롤업 / 롤다운 / 최소화** 아이콘만 배치했습니다. 마우스를 올리면 기능 이름이 나타납니다.
- 하단은 마지막으로 성공한 **최근 갱신 시각 한 줄**만 표시합니다. 갱신 이력이 없으면 ‘최근 갱신 기록 없음’으로 표시합니다. 통신·저장 오류는 별도 알림으로 안내하며 최근 정상 갱신 시각을 유지합니다.
- 말풍선을 더블클릭하면 기본 브라우저에서 **Google Sheets 목록**을 엽니다.
- 롤업은 본문을 접고 상·하단 바만 남깁니다. 롤다운은 펼쳐진 높이와 읽던 스크롤 위치를 복원합니다. 최소화는 위젯 전체를 트레이로 숨깁니다.
- 꼬리는 **왼쪽 / 오른쪽 / 없음**, 모양은 **둥근 사각형 / 사각형 / 물방울형 / 캡슐형 / 모서리 컷** 중 선택합니다. 오른쪽 꼬리를 고르면 말풍선도 오른쪽에 정렬됩니다.
- **파스텔 12종**: 민트, 하늘, 라벤더, 로즈, 복숭아, 레몬, 청록, 라일락, 피스타치오, 살구, 블루베리, 구름. 배경색과 어울리는 글자색이 함께 적용됩니다.
- 배경색·글자색을 Windows 색상 선택창 또는 `#RRGGBB` 입력으로 직접 지정할 수 있습니다.
- **유리판과 말풍선 배경의 불투명도를 별도로 조절**합니다. 두 슬라이더 모두 **0% 완전 투명 → 100% 완전 불투명**입니다. 기본값은 유리판 60%, 말풍선 100%입니다.
- 메모 글꼴은 컴퓨터에 설치된 글꼴 중 선택합니다. 크기 **11~36**, 굵게, 기울임을 조절하며 글자는 배경 불투명도와 별도로 표시합니다.
- 설정은 **말풍선 / 유리판 / 연결·동작** 세 탭으로 나눴습니다. 미리보기와 실제 위젯에 즉시 표시하며, 저장으로 확정하고 취소·X·ESC로 원래 외형을 복원합니다.
- 같은 내용으로 새로고침하면 읽던 위치를 유지합니다. 내용이 바뀌면 기존 스크롤 높이를 가능한 범위에서 유지하고, 다른 시트를 연결하면 처음부터 표시합니다.

## 메모 동작

- A1부터 A열의 비어 있지 않은 셀을 위에서 아래로 표시합니다. **별도 제목 행은 없습니다.**
- 셀 하나가 메모 하나입니다. 줄바꿈, 쉼표, 따옴표, 공백, 한글, 기호를 보존합니다.
- 날짜, todo, done 등의 단어는 일반 문자로 표시합니다.
- B열 이후의 내용과 글꼴·색상·굵게 같은 시트 서식은 표시하지 않습니다.
- 기본은 수동 갱신입니다. ‘실행할 때 한 번 새로고침’만 선택 사항으로 제공합니다.
- 연결이 실패하면 마지막 정상 메모와 마지막 확인 시각을 유지합니다.
- 정상적으로 빈 시트를 받았을 때는 기존 목록을 비우고 빈 메모 안내를 표시합니다.
- 설정창에는 주소 등록 여부만 표시합니다. 기존 주소 조회·복사·내보내기 기능은 없습니다.
- ‘구글 시트’ 버튼은 언제나 https://docs.google.com/spreadsheets/ 를 기본 브라우저로 엽니다.
- 프로그램은 로그인·수정·업로드를 수행하지 않습니다. 구글 계정은 브라우저에서 관리합니다.

## 빠른 시작

1. 소스 ZIP을 풀고 아래 Visual Studio 안내에 따라 빌드·실행합니다.
2. Google Sheets 목록에서 새 스프레드시트를 만듭니다.
3. **파일 → 가져오기 → 업로드**에서 `templates/MyToDo_Template.csv`를 선택합니다.
4. 가져오기 과정에 ‘텍스트를 숫자, 날짜, 수식으로 변환’ 옵션이 있으면 해제합니다.
5. A열 전체를 선택하고 **서식 → 숫자 → 일반 텍스트**로 지정합니다. 원하는 경우 텍스트 줄바꿈도 설정합니다.
6. 예시를 지우고 A1부터 자신의 메모를 입력합니다. 셀 안 줄바꿈은 Windows에서 `Alt+Enter`입니다.
7. **파일 → 공유 → 웹에 게시**에서 메모를 적은 **개별 탭**을 선택하고 **쉼표로 구분된 값(.csv)** 형식으로 게시합니다.
8. 게시된 콘텐츠가 수정 시 자동으로 다시 게시되도록 설정한 상태에서 CSV 주소를 복사합니다.
9. 위젯의 설정 → 연결·동작 → 새 주소 입력란에 붙여넣고 **저장**합니다. 최초 연결을 확인한 뒤 메모를 표시합니다.
10. 이후에는 위젯의 **새로고침** 또는 `F5`로 갱신합니다.

일반 ‘링크 공유’ 주소나 `/edit` 주소는 지원하지 않습니다. ‘웹에 게시’로 얻은 CSV 주소를 사용합니다.
같은 게시 기능의 `pubhtml` 주소도 내부에서 CSV 읽기 주소로 바꾸지만, 처음부터 CSV 형식을 선택하는 방법을 권합니다.
CSV 주소에 선택한 탭의 `gid`가 포함되어 있으면 이를 보존합니다. 탭 번호가 없는 주소는 Google이 반환하는 기본 탭을 읽습니다.

CSV에는 셀 서식이 저장되지 않습니다. 날짜를 자유 텍스트로 유지하려면 입력 전에 A열을 일반 텍스트로 설정해야 합니다.
시트에서 이미 날짜·숫자·수식으로 변환한 내용은 위젯에서 원래 입력 문자로 복원하지 않습니다.

## 다른 컴퓨터에서 사용

새 컴퓨터에서 프로그램을 실행하고 동일한 CSV 게시 주소를 한 번 등록합니다.
등록 후에는 브라우저를 열지 않고 ‘새로고침’만 누르면 됩니다.
기존 주소는 위젯에서 꺼낼 수 없으므로, 새 컴퓨터에 등록할 때 Google Sheets의 게시 설정에서 다시 복사합니다.

주소와 마지막 메모는 `%LOCALAPPDATA%\MyToDoWidget\state.dat`에 Windows 사용자별 DPAPI로 보호하여 저장합니다.
주소가 평문 설정 파일에 들어가지 않으며, 주소나 서버 응답 내용을 로그로 남기지 않습니다.
실행 파일만 복사하면 되고 이 저장 파일을 다른 컴퓨터로 옮길 필요는 없습니다.
프로그램이 같은 사용자 계정으로 실행되는 동안 필요한 주소를 복호화하므로, 이것은 화면·파일의 우발적 노출을 줄이는 기능입니다.
게시된 시트를 비공개로 바꾸는 기능은 아닙니다.

## 화면과 조작

| 조작 | 동작 |
|---|---|
| 상단 MyToDo 영역 끌기 | 위젯 이동 |
| 펼친 창 가장자리·모서리 끌기 | 크기 조절 |
| 말풍선 위에서 휠 / 오른쪽 스크롤바 | 긴 메모와 다음 메모 확인 |
| 상단 새로고침 아이콘 / F5 | 수동 갱신 |
| 구글 시트 아이콘 / 말풍선 더블클릭 | Google Sheets 목록을 기본 브라우저로 열기 |
| 설정 아이콘 | 말풍선·글꼴·유리판·연결·동작 설정 |
| 롤업 아이콘 | 본문 접기. 위젯은 바탕화면에 남음 |
| 롤다운 아이콘 | 본문과 이전 높이 복원 |
| 최소화 아이콘 / Alt+F4 | 위젯 전체를 트레이로 숨김 |
| 메모 선택 후 Ctrl+C / 우클릭 | 선택한 메모 복사 |
| 트레이 아이콘 더블클릭 | 위젯 표시 |
| 트레이 → 주 모니터로 가져오기 | 화면 밖에 있는 위젯 복구 |
| 트레이 → 종료 | 프로그램 완전 종료 |

유리판은 바탕화면이 비치는 투명 창에 색과 은은한 빛 반사를 더한 표현이며, 시스템 Acrylic 블러는 사용하지 않습니다.
유리판 0%에서는 유리판 색·외곽선·빛 반사가 사라집니다. 상·하단 조작 바와 메모 글씨는 남으며, 말풍선 배경은 별도 슬라이더를 따릅니다.
배경을 모두 0%로 설정한 경우 글자나 세로 스크롤바 위에서 휠을 사용하세요. 완전히 투명한 빈 부분은 아래 창으로 마우스 입력이 전달될 수 있습니다.
접힌 상태에서는 크기 조절 손잡이를 숨기며, 펼치면 다시 사용할 수 있습니다. 접힌 상태도 종료 후 다시 실행할 때 유지합니다.
사용자 지정 글꼴이 다른 컴퓨터에 없으면 Windows의 대체 글꼴로 표시될 수 있습니다. 글꼴 파일을 함께 배포하지 않습니다.
일반적인 독립 창으로 동작하며, `Win+D`에 대한 ‘항상 바탕화면에 남기기’ 특수 처리는 하지 않습니다.
Windows 시작프로그램에는 등록하지 않습니다.

## 연결 변경과 복구

- 새 주소는 실제 CSV를 읽는 데 성공한 뒤 적용합니다. 실패하면 기존 주소와 메모를 유지합니다.
- 주소 입력란을 비우고 저장하면 현재 주소가 유지됩니다.
- **연결 해제 → 저장**은 이 컴퓨터의 연결·캐시를 지웁니다. Google Sheets 원본을 삭제하지 않습니다.
- 설정과 메모는 하나의 보호된 상태 파일로 함께 저장하여 주소와 캐시가 서로 다른 문서를 가리키지 않게 합니다.
- 저장 시 임시 파일을 만든 뒤 교체하고, 이전 정상 상태의 `.bak`를 보관합니다.
- 연결 해제·교체 시 이전 연결의 백업을 제거하여 이전 연결이 복원되지 않게 합니다. 이후 정상 저장부터 새 연결의 백업을 만듭니다.
- 읽기 제한은 게시 CSV 2MiB, 메모 5,000개, A열 셀 하나당 50,000자입니다.

## Visual Studio 빌드

이번 패키지는 **소스 전용**입니다. 실행 파일, DLL, bin/obj, 배포 ZIP을 포함하지 않습니다.
프로젝트 대상은 .NET 10 WPF입니다. .NET 10을 지원하는 Visual Studio에 **.NET 데스크톱 개발** 워크로드를 설치합니다.

1. 소스 ZIP을 완전히 풉니다.
2. 이전 버전이 실행 중이면 트레이 → **종료**로 닫습니다. 숨기기만 하면 기존 프로그램이 계속 실행됩니다.
3. `MyToDoWidget.sln`을 엽니다.
4. 솔루션 탐색기에서 **MyToDoWidget** 프로젝트를 시작 프로젝트로 지정합니다.
5. 구성을 Release로 선택하고 **빌드 → 솔루션 빌드**, 실행은 `F5` 또는 `Ctrl+F5`를 사용합니다.

`MyToDoWidget.Core`와 `MyToDoWidget.Checks`는 위젯의 시작 프로젝트가 아닙니다.
첫 빌드에는 Microsoft 대상 팩 등 필요한 구성 요소를 내려받기 위한 인터넷 연결이 필요할 수 있습니다.
기존 `build_release.bat`는 사용자가 별도로 배포본을 만들 때 선택해서 실행하는 도구로 유지했습니다. 솔루션 빌드에서 자동 실행하지 않습니다.

## 이전 버전에서 업데이트

- 같은 Windows 사용자 계정에서 실행하면 기존 주소·캐시·창 위치·글자 크기·테마를 읽습니다.
- 저장 파일 경로와 스키마, 중복 실행 방지 이름을 유지했습니다.
- 저장된 유리판 농도는 유지하고 표시 방향만 바꿉니다. 예를 들어 0.2.0의 ‘투명도 40%’는 0.3.0의 ‘불투명도 60%’가 되므로 실제 비침 정도는 같습니다.
- 이전 ‘유리 효과’ 선택값은 ‘유리판에 은은한 빛 반사’에 이어집니다.
- 새 말풍선 설정은 민트·둥근 사각형·왼쪽 꼬리로 시작합니다. 사용자가 선택한 모양·색·글꼴·불투명도는 이 컴퓨터에 저장합니다.
- 기존의 펼친 창 크기는 유지됩니다. 롤업의 작은 높이를 펼친 높이로 덮어쓰지 않습니다.

### 로직 검증

`run_checks.bat` 또는 다음 명령을 실행합니다.

```text
dotnet run --project tests/MyToDoWidget.Checks -c Release -- templates/MyToDo_Template.csv
```

검증 범위와 남은 Windows 확인 항목은 `docs/VALIDATION.md`에 기록했습니다.

## 프로젝트 구조

- `src/MyToDoWidget`: WPF 화면, 트레이, Windows 보호 저장, 창 동작
- `src/MyToDoWidget.Core`: CSV 읽기, 게시 주소 확인, HTTP 읽기, 상태 저장, 말풍선 설정 값
- `tests/MyToDoWidget.Checks`: 외부 테스트 패키지 없이 실행하는 핵심 로직 검증
- `templates/MyToDo_Template.csv`: 업로드용 한 열 자유 메모 예시
- `docs/QUICK_START_KO.txt`: 사용 안내

MyToDo2 2.0.1 / MathTime

빠른 시작
1. 배포 ZIP 전체를 풀고 MyToDo2.exe를 실행합니다.
2. 상단 M은 메모, S는 일정입니다. ＋ / Ctrl+N으로 추가합니다.
3. 말풍선 더블클릭 / 연필로 편집합니다.
4. 항목 화살표는 1줄 → 2줄 → 전체 보기입니다.
5. 설정·구글 시트 열기·프로그램 종료는 우클릭 메뉴에 있습니다.

여러 PC에서 사용
우클릭 → 설정 → 시트 연결에서 켜지는 버튼을 순서대로 누릅니다.
내 시트 만들기 → 설치 코드 붙여넣기·실행 → 웹 앱 배포 → 전용 코드 연결
처음 한 번 Code.gs에 설치 코드 전체를 붙여넣습니다. 개발자 템플릿 주소는 사용하지 않습니다.
다른 PC에도 같은 전용 코드를 등록합니다. 연결 전에는 이 PC에만 저장합니다.

동기화와 백업
• 편집 저장 후 변경사항을 전송합니다.
• 실행 직후 연결된 시트를 한 번 조회합니다.
• 다른 PC의 변경은 기본 30분마다 확인합니다. 지금 동기화는 F5입니다.
• 순서 변경도 시트에 저장하며 다른 PC는 동기화 후 같은 순서로 표시합니다.
• 구글 시트 연결정보는 백업하지 않음
• 백업 파일은 암호화되지 않으므로 안전한 곳에 보관
• 개인 시트는 제한됨으로 유지하고 전용 코드는 공개하지 마세요.

한 셀이 하나의 메모입니다. 날짜나 제목 형식에 맞출 필요 없이 A열에 자유롭게 입력하세요. 글을 쓰고 수정하는 곳은 구글 시트, 읽는 곳은 MyToDo입니다.

민감한 메모는 입력하지 않는 것을 권장합니다. ‘링크가 있는 모든 사용자 · 뷰어’는 수정을 막지만, 링크를 아는 사람은 로그인 없이 내용을 읽을 수 있습니다. 주소를 숨겨도 공유된 내용이 비공개로 바뀌지는 않습니다.

공유 권한은 파일 전체에 적용됩니다. A열만 표시해도 다른 열·탭의 열람이 차단되지는 않으며, 파일 소유자의 이름·이메일도 표시될 수 있습니다. 메모 전용 파일을 사용하세요.

01

빠른 시작

처음 한 번 연결해 두면, 다음부터는 시트를 열지 않고 메모를 불러옵니다.

  1. 실행용 ZIP을 내려받아 원하는 폴더에 압축을 풀고 MyToDoWidget.exe를 실행합니다. standalone 배포본은 .NET을 따로 설치하지 않아도 됩니다.
  2. Google Sheets에서 메모 전용 스프레드시트 파일을 만듭니다.
  3. 위젯 우클릭 → 설정 → 간편 설정 및 사용법 → CSV 템플릿 저장에서 예시를 저장하고, 구글 시트의 파일 → 가져오기 → 업로드로 가져옵니다. A1부터 직접 작성해도 됩니다.
  4. A열을 서식 → 숫자 → 일반 텍스트로 지정하고 메모를 적습니다. 제목 행은 필요하지 않습니다. 셀 안 줄바꿈은 Alt+Enter입니다.
  5. 오른쪽 위 공유 → 일반 액세스 → 링크가 있는 모든 사용자 → 뷰어를 선택하고 완료합니다.
  6. 메모를 적은 탭을 열고 브라우저 주소를 복사하여 위젯 설정 → 연결·동작에 넣고 저장합니다. 탭 번호가 없는 일반 공유 링크는 첫 탭을 읽습니다.
  7. 수정 후 새로고침 또는 F5를 누릅니다. 다른 PC에도 같은 공유 주소를 처음 한 번 등록합니다.

‘웹에 게시’와 OAuth 인증은 필요하지 않습니다. 위젯은 Google 로그인 정보와 브라우저 쿠키를 가져오지 않으며, 시트 편집은 브라우저에서 합니다.

02

이번 버전 변경 사항

MyToDo 1.1.2문서 기준: 2026.10.05.
  • 구글 시트 일반 공유 링크를 사용합니다. ‘링크가 있는 모든 사용자 · 뷰어’로 설정하며 웹에 게시나 OAuth 인증은 필요하지 않습니다.
  • 민감한 메모 입력을 권장하지 않는 이유를 설정·사용법·정보와 이 페이지에 안내합니다.
  • 환경설정창을 밝은 테마로 고정하고 드롭다운의 선택값·목록 글자색을 개선했습니다. 유리판의 ‘밝은 테마’ 옵션을 제거했습니다.
  • 말풍선 내부의 위아래 여백을 줄여 짧은 메모도 더 간결하게 보이도록 했습니다.
  • 라이선스·외부 구성요소·AI 개발 도구 활용 표기와 검증 기록을 정리했습니다. 이후 Apps Script 연동 계획도 포함합니다.
03

주요 기능

기능설명
자유 메모A1부터 A열의 비어 있지 않은 셀을 위에서 아래로 읽습니다. 셀 하나가 말풍선 하나이며 줄바꿈·한글·기호를 유지합니다.
Windows 자동 실행연결·동작 탭에서 선택하면 현재 Windows 계정으로 로그인할 때 시작합니다. 저장으로 적용하며 기본값은 꺼짐입니다.
한 번에 새로고침버튼이나 F5로 다시 불러옵니다. 선택하면 실행할 때 한 번 갱신합니다. 연결이 실패하면 마지막 정상 메모를 유지합니다.
말풍선 배치왼쪽·가운데·오른쪽 정렬, 내용에 맞춘 폭·위젯 폭, 0~40의 수직 간격을 조절합니다. 정렬은 꼬리 방향과 독립적입니다.
모양과 꼬리둥근 사각형·사각형·물방울형·캡슐형·모서리 컷을 제공합니다. 꼬리는 왼쪽·오른쪽·없음 중 선택합니다.
색상과 글꼴말풍선 파스텔 12종, 유리판 테마 8종과 사용자 색상을 제공합니다. 글자색·글꼴·크기·굵게·기울임을 조절하며 설치된 한글 고정폭 글꼴을 우선 추천합니다.
유리판과 불투명도유리판·말풍선·상단바 배경·흰색 테두리를 따로 조절합니다. 0%는 완전 투명, 100%는 완전 불투명입니다. 글자와 조작 아이콘은 또렷하게 유지합니다.
작은 상단바제목과 아이콘, 최근 정상 갱신 시각, 새로고침·접기/펼치기·최소화·▲▼를 한 줄에 표시합니다. 좁은 폭에서는 갱신 시각을 줄이거나 숨기고 툴팁으로 확인합니다.
읽기와 크기 조절마우스 휠 또는 ▲▼로 읽습니다. 창 크기에 맞춰 글자를 확대·축소하거나 고정 크기로 표시합니다. 가로 폭은 180 DIP까지 줄일 수 있습니다.
잠금·절전 복귀화면 구성이 안정되면 저장 위치 복원을 시도합니다. 화면 밖 위젯은 트레이 메뉴에서 주 모니터로 가져옵니다.
밝은 환경설정설정창은 밝은 테마로 고정됩니다. 위젯의 색상·불투명도는 별도로 꾸밀 수 있습니다.
연결 정보 보관등록 여부만 보여 주고 저장된 주소는 다시 표시하지 않습니다. 위젯은 Google 로그인을 요구하지 않습니다. 시트 편집에 필요한 로그인은 기본 브라우저에서 관리합니다.

날짜·todo·done은 일반 텍스트입니다. 날짜 자동 정렬이나 완료 체크, 시트로 다시 쓰기는 지원하지 않습니다. B열 이후의 내용과 시트의 글꼴·색상 서식은 위젯에 표시하지 않습니다.

04

기본 조작

설정과 시트 열기

위젯을 우클릭해 설정이나 구글 시트 열기를 선택합니다. 말풍선 더블클릭도 구글 시트 목록을 엽니다. 로그인된 브라우저에서는 자신의 시트를 고를 수 있습니다.

위치와 크기

상단 제목·빈 곳을 끌어 옮기고, 펼친 창의 가장자리·모서리를 끌어 크기를 바꿉니다. 이동 중 Esc를 누르면 취소합니다. 기본 창 끌기의 타일 배치를 호출하지 않습니다.

접기와 최소화

접기는 본문을 접고 상단바만 남깁니다. 다시 펼치면 높이와 읽던 위치를 복원합니다. 최소화는 위젯 전체를 트레이로 숨깁니다.

다시 표시와 종료

트레이 아이콘을 더블클릭하면 위젯이 나타납니다. 완전히 종료하려면 트레이 우클릭 → 종료를 선택합니다. Alt+F4는 숨기기로 동작합니다.

메모 읽기와 복사

메모 위에서 휠을 돌리거나 ▲▼를 누릅니다. 화살표는 길게 눌러 연속 이동할 수 있습니다. 메모를 선택한 뒤 Ctrl+C로 복사합니다.

꾸미기 미리보기

말풍선·유리판 설정은 즉시 미리 볼 수 있습니다. 저장으로 확정하고 취소·Esc로 원래 외형을 복원합니다. 위젯 폭 모드에서는 정렬 선택이 잠시 비활성화됩니다.

05

Windows 시작 시 자동 실행

컴퓨터를 켜고 현재 Windows 계정에 로그인할 때 위젯을 자동으로 엽니다.

  1. 위젯 우클릭 → 설정 → 연결·동작을 엽니다.
  2. Windows 시작 시 자동 실행을 켜고 저장합니다. 처음에는 꺼져 있으며 취소하면 등록하지 않습니다.
  3. 최신 메모도 불러오려면 실행할 때 한 번 새로고침을 함께 선택합니다.
  4. 자동 실행을 해제하려면 같은 옵션을 끄고 저장합니다.

EXE를 옮겼다면 새 위치에서 한 번 직접 실행하세요. 이미 등록된 경로만 갱신합니다. Windows 시작 앱에서 차단한 경우 그곳에서도 사용으로 바꾸어야 합니다. Windows가 로그인 후 실행을 잠시 늦출 수 있습니다.

06

저장과 업데이트

  • 설정·연결 주소·마지막 메모는 %LOCALAPPDATA%\MyToDoWidget\state.dat에 Windows 사용자 계정으로 암호화하여 저장합니다.
  • 저장할 때 이전 정상 상태를 백업합니다. 연결 실패 시 마지막 메모·갱신 시각을 유지하며, 정상적으로 빈 A열을 받으면 목록을 비웁니다.
  • 업데이트 전 트레이에서 기존 앱을 완전히 종료하고 새 실행용 ZIP을 풉니다. 1.0.x의 웹 게시 주소는 연결·캐시를 해제하고 일반 공유 주소를 다시 등록하도록 안내합니다. 외형 설정은 유지합니다.
  • 이전 웹 게시본은 Google Sheets에서 별도로 게시 중지하세요. 위젯의 연결 변경·해제는 Google 공유 권한을 변경하지 않습니다.
  • 검토용 1.1.x의 설정은 정식판과 별도 폴더에 있습니다. 정식판에는 공유 주소를 다시 등록하세요.
  • 다른 PC에도 같은 일반 공유 주소를 한 번 등록합니다. 글꼴과 외형은 각 PC에서 선택하며 설치되지 않은 글꼴은 Windows 대체 글꼴로 표시합니다.
  • 자동 실행 중 EXE를 옮기면 새 위치에서 한 번 직접 실행하세요. 앱 삭제 전 자동 실행을 끄고 저장합니다.
07

자주 묻는 질문

시트를 고쳤는데 메모가 바뀌지 않아요.

새로고침 또는 F5를 누르세요. 연결한 탭의 A열인지 확인합니다. 접근 오류가 발생하면 마지막 정상 메모를 유지하므로 갱신 시각과 오류 안내도 확인하세요.

어떤 주소를 등록해야 하나요?

일반 액세스를 ‘링크가 있는 모든 사용자 · 뷰어’로 설정한 뒤 메모 탭을 연 브라우저 주소를 등록합니다. ‘웹에 게시’ 주소는 사용하지 않습니다. 조직 정책이나 다운로드 제한으로 읽기가 막힐 수 있습니다.

뷰어로 설정하면 메모는 비공개인가요?

뷰어는 수정을 막는 권한입니다. 링크를 아는 사람은 로그인 없이 읽을 수 있습니다. 민감한 내용을 입력하지 마세요. 접근을 막으려면 Google Sheets에서 일반 액세스를 ‘제한됨’으로 바꾸어야 하며, 그러면 위젯도 새 메모를 읽지 못합니다.

투명하게 하니 휠이 작동하지 않는 곳이 있어요.

완전히 투명한 빈 곳은 아래 창으로 입력이 전달될 수 있습니다. 글자 위에서 휠을 사용하거나 상단 ▲▼를 누르세요. 배경 불투명도를 조금 올려도 됩니다.

위젯이 화면에 보이지 않아요.

트레이 아이콘을 더블클릭해 표시합니다. 그래도 보이지 않으면 트레이 우클릭 → 주 모니터로 가져오기를 선택하세요.

여러 PC에서 동시에 편집할 수 있나요?

각 PC의 브라우저에서 구글 시트를 편집합니다. MyToDo는 시트를 수정하지 않고 공유된 내용을 읽습니다. 같은 주소를 연결하고 새로고침하여 확인하세요.

다운로드 파일 확인

배포 ZIP과 함께 제공되는 .sha256 파일의 값과 다운로드한 ZIP의 해시를 비교합니다.

ZIP을 내려받은 폴더에서 실행할 Windows 명령
certutil -hashfile MyToDoWidget-1.1.2-win-x64.zip SHA256

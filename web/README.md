# MathTime MyToDo 페이지

`mytodo.html`은 기존 MathTime SPA의 콘텐츠 조각입니다.
기존 `dday.html`과 같은 위치에 적용하며 `/js/redirect.js`와 `?page=mytodo` 경로를 사용합니다.
CSS는 `#mytodo-page` 범위에 한정했습니다.

저장소는 `lottoria-dev/MyToDoWidget`, 정식 태그는 `1.1.2`입니다.
실행용 ZIP과 체크섬을 GitHub에 업로드한 다음 이 페이지를 적용하세요.
업로드 전 미리보기에서는 `data-release-ready="false"`로 바꾸면 Releases 목록으로 연결됩니다.
전체 공개 순서는 [GITHUB_PUBLISH.md](../docs/GITHUB_PUBLISH.md)를 확인하세요.

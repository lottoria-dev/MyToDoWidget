# MyToDo 1.1.2

구글 시트에 자유롭게 적은 메모를 Windows 바탕화면 말풍선으로 읽는 위젯입니다.
이번 정식 버전은 일반 공유 링크 연결, 환경설정 가독성 개선과 말풍선 내부 여백 축소를 포함합니다.

## 변경 사항

- ‘링크가 있는 모든 사용자 · 뷰어’로 설정한 일반 공유 주소를 사용합니다. 웹에 게시와 OAuth는 필요하지 않습니다.
- 민감한 메모 입력을 권장하지 않는 이유를 설정·사용법·정보·홈페이지에 안내합니다.
- 환경설정창을 밝은 테마로 고정하고 드롭다운 선택값·목록 글자색을 개선했습니다. 유리판의 ‘밝은 테마’ 옵션을 제거했습니다.
- 말풍선 내부 상하 padding을 각각 12 DIP에서 8 DIP로 줄였습니다. 실제 위젯과 설정 미리보기에 함께 적용됩니다.
- README의 AI 개발 도구 활용 표기와 LICENSE.md, THIRD_PARTY_NOTICES.md, VALIDATION.md를 정리했습니다.
- 정식판 빌드를 기본값으로 복원하고 이후 Apps Script 전환 계획을 기록했습니다.

## 연결과 업데이트

민감한 메모는 입력하지 않는 것을 권장합니다. 뷰어는 수정을 막지만, 링크를 아는 사람은 로그인 없이 내용을 읽을 수 있습니다.
공유 권한은 파일 전체에 적용되므로 메모 전용 스프레드시트를 사용하세요.

1. 기존 앱을 트레이에서 완전히 종료합니다.
2. 새 실행용 ZIP을 원하는 폴더에 풉니다.
3. 1.0.x 웹 게시 주소는 일반 공유 주소로 다시 등록합니다. 외형 설정은 유지하며 이전 연결·메모 캐시는 해제합니다.
4. 기존 웹 게시본은 Google Sheets에서 별도로 게시 중지합니다. 위젯은 Google 공유 권한을 변경하지 않습니다.
5. 검토용 1.1.x에서 이동할 때는 정식판의 별도 설정에 공유 주소를 다시 등록합니다.
6. 자동 실행을 사용하는 경우 새 위치에서 한 번 직접 실행하여 등록 경로를 갱신합니다.

## 배포 파일

- Windows x64 실행용: `MyToDoWidget-1.1.2-win-x64.zip` — .NET 런타임 포함
- 실행용 ZIP 체크섬: `MyToDoWidget-1.1.2-win-x64.zip.sha256`
- GitHub 공개용 소스: `MyToDoWidget_1.1.2_GitHub.zip`
- 태그: `1.1.2` — `v` 없음

소스 ZIP에는 실행 파일이 없습니다. 실행용 ZIP과 체크섬은 개발자의 Windows 환경에서 빌드·검증 후 첨부합니다.
수행한 검사와 남은 Windows 확인은 [VALIDATION.md](../VALIDATION.md)에 기록했습니다.

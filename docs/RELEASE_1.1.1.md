# MyToDo 1.1.1 검토용

- 1.x의 연결 정책을 ‘링크가 있는 모든 사용자 · 뷰어’로 확정했습니다.
- 일반 공유·편집 화면 주소를 CSV 읽기 주소로 변환하고 탭 번호를 유지합니다.
- Google 계정 로그인이나 OAuth 설정 없이 메모를 읽습니다.
- 연결·사용법·정보 탭과 사용자 안내에 민감한 메모 입력 비권장 및 이유를 표시합니다.
- 저장된 주소를 숨기고 Windows 사용자별로 주소·메모를 암호화하는 기존 구조를 유지합니다.
- 기존 ‘웹에 게시’ 주소는 새로 등록하지 않습니다. 정식 설정 이전 시 외형을 유지하고 새 연결을 안내합니다.
- 이후 Apps Script 적용을 ROADMAP.md에 기록했습니다. 현재 구현에는 포함하지 않았습니다.
- 공식 제작자는 MathTime, 저장소는 lottoria-dev/MyToDoWidget입니다.
- 기본 빌드는 정식판과 설정·인스턴스·자동 실행 등록을 분리한 검토용입니다.

이번 결과물은 소스 전용입니다. 실행 파일·정식 GitHub 배포 묶음·홈페이지 게시본은 생성하지 않습니다.

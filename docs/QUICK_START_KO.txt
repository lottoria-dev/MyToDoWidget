MyToDo Widget 0.3.0 — 소스 패키지

1. Visual Studio에서 MyToDoWidget.sln을 열고 MyToDoWidget을 시작 프로젝트로 지정하여 빌드·실행합니다.
2. https://docs.google.com/spreadsheets/ 에서 새 시트를 만듭니다.
3. 파일 → 가져오기 → 업로드에서 templates 폴더의 MyToDo_Template.csv를 가져옵니다.
4. 가져오기 창에 텍스트를 숫자·날짜·수식으로 변환하는 옵션이 있으면 해제합니다.
5. A열을 선택하고 서식 → 숫자 → 일반 텍스트로 설정합니다.
6. 예시를 지우고 A1부터 메모를 자유롭게 입력합니다. 셀 하나가 메모 하나입니다.
   셀 안의 여러 줄 입력은 Alt+Enter입니다. 날짜도 원하는 말로 입력하세요.
7. 파일 → 공유 → 웹에 게시에서 메모 탭 하나와 CSV 형식을 선택해 게시합니다.
   수정 시 자동으로 다시 게시하는 설정을 유지합니다.
8. CSV 게시 주소를 복사하여 위젯 설정에 붙여넣고 저장합니다.
9. 이후에는 위젯의 ‘새로고침’ 또는 F5를 누릅니다.

알아둘 점

- 일반 ‘공유’ 주소가 아닌 ‘웹에 게시’의 CSV 주소가 필요합니다.
- A열의 비어 있지 않은 셀만 순서대로 표시합니다. 제목 행을 따로 두지 않습니다.
- ‘구글 시트’ 버튼은 특정 문서가 아닌 Google Sheets 목록을 엽니다.
- 저장된 주소는 화면에서 확인하거나 복사할 수 없습니다.
- 다른 컴퓨터에서는 Google Sheets의 게시 설정에서 주소를 다시 복사해 한 번 등록합니다.
- 기본은 수동 갱신입니다. 설정에서 실행 시 한 번 불러오기를 선택할 수 있습니다.
- 게시본 반영에는 몇 분이 걸릴 수 있습니다. 잠시 뒤 다시 불러오세요.
- 연결 실패 시 마지막으로 받은 메모가 남습니다. 정상적으로 빈 A열을 받으면 목록을 비웁니다.
- 프로그램은 Google Sheets를 수정하거나 로그인 정보를 저장하지 않습니다.

창 사용

- 상단 아이콘 순서: 새로고침 / 구글 시트 / 설정 / 롤업 / 롤다운 / 최소화
- 상단 MyToDo 영역을 끌어 이동, 펼친 창 가장자리로 크기 변경
- A열 셀 하나가 말풍선 하나로 표시됨. 위에서 마우스 휠로 읽기
- 말풍선을 더블클릭하면 Google Sheets 목록 열기
- 롤업은 본문을 접고, 롤다운은 이전 높이와 읽던 위치를 복원
- 최소화나 Alt+F4는 위젯 전체를 트레이로 숨기기
- 하단 한 줄에는 최근 정상 갱신 시각만 표시
- 메모 선택 후 Ctrl+C 또는 우클릭으로 복사
- 트레이 아이콘 더블클릭은 다시 표시, 우클릭의 종료는 완전 종료
- 창이 보이지 않으면 트레이 → 주 모니터로 가져오기

꾸미기

- 설정 → 말풍선: 5가지 모양, 꼬리 왼쪽/오른쪽/없음, 파스텔 12종
- 배경색과 글자색을 색상 선택창이나 #RRGGBB로 직접 지정
- 설치된 글꼴 선택, 글자 크기 11~36, 굵게·기울임
- 말풍선 배경과 유리판 불투명도는 각각 별도로 조절
- 두 슬라이더 모두 0% 완전 투명, 100% 완전 불투명
- 즉시 미리보기, 저장으로 확정, 취소·X·ESC로 원래 외형 복원
- 배경을 모두 0%로 설정하면 글자나 스크롤바 위에서 휠 사용
- 설정 → 연결·동작에서 주소 등록과 항상 위·위치 잠금 등 조절

이 패키지에는 실행 파일이 없습니다. .NET 10을 지원하는 Visual Studio와 .NET 데스크톱 개발 워크로드를 사용하세요.
이전 버전은 트레이에서 완전히 종료한 뒤 새 버전을 실행하세요. 기존 연결과 메모는 이어서 사용합니다.
유리판은 바탕화면이 비치는 반투명 표현이며 시스템 Acrylic 블러는 사용하지 않습니다.
설정과 마지막 메모는 Windows 사용자별 로컬 저장소에 보관합니다.
주소를 화면에서 숨겨도 게시한 시트 자체는 공개된 읽기 자료입니다.

MyToDo 1.1.2 빠른 시작 / MathTime

Windows x64 standalone 배포 ZIP의 압축을 풀고 MyToDoWidget.exe를 실행하세요.
.NET 런타임은 배포본에 포함됩니다. GitHub 소스 ZIP은 Visual Studio에서 직접 빌드해야 합니다.

민감한 메모는 입력하지 않는 것을 권장합니다.
‘링크가 있는 모든 사용자 · 뷰어’는 수정을 막지만, 링크를 아는 사람은 로그인 없이 내용을 읽을 수 있습니다.
공유 권한은 파일 전체에 적용되므로 메모 전용 스프레드시트 파일을 만드세요.

1. https://docs.google.com/spreadsheets/ 에서 새 파일을 만듭니다.
2. templates/MyToDo_Template.csv를 가져오거나 A1부터 메모를 작성합니다.
   위젯의 설정 → 간편 설정 및 사용법 → CSV 템플릿 저장에서도 예시 파일을 꺼낼 수 있습니다.
3. A열을 일반 텍스트로 지정합니다. 한 셀이 하나의 메모이며 제목 행은 없습니다.
   셀 안 줄바꿈은 Alt+Enter입니다. 날짜·todo·done도 자유로운 텍스트입니다.
4. 공유 → 일반 액세스 → 링크가 있는 모든 사용자 → 뷰어를 선택하고 완료합니다.
5. 메모 탭을 열고 브라우저 주소를 복사합니다. 탭 번호가 없는 공유 링크는 첫 탭을 읽습니다.
6. 위젯 우클릭 → 설정 → 연결·동작에 주소를 붙여넣고 저장합니다.
7. 수정 후 새로고침 또는 F5를 누릅니다. 다른 PC에도 같은 주소를 한 번 등록합니다.

웹에 게시, Google 로그인 또는 OAuth 인증은 위젯에서 요구하지 않습니다.
설정에는 저장된 주소를 보여 주지 않고 등록 여부만 표시합니다.
말풍선 더블클릭 / 우클릭 → 구글 시트 열기는 기본 브라우저에서 구글 시트 목록을 엽니다.

휠 / 상단 ▲▼: 스크롤
상단 제목·빈 곳 끌기: 이동
펼친 위젯 가장자리·모서리 끌기: 크기 조절
접기·펼치기: 본문 접기와 이전 높이·스크롤 복원
최소화 / Alt+F4: 트레이로 숨기기
트레이 더블클릭: 다시 표시 / 트레이 → 종료: 완전 종료
환경설정: 밝은 테마로 고정 / 저장: 적용 / 취소·Esc: 외형 되돌리기
불투명도: 0% 완전 투명, 100% 완전 불투명

Windows 시작 시 자동 실행은 설정 → 연결·동작에서 켜고 저장합니다.
기본값은 꺼짐입니다. 실행할 때 한 번 새로고침은 별도 선택입니다.
EXE를 옮긴 뒤 새 위치에서 한 번 실행하면 기존 자동 실행 등록의 경로를 갱신합니다.
프로그램을 삭제하기 전에는 자동 실행을 끄고 저장하세요.

정식판 설정: %LOCALAPPDATA%\MyToDoWidget\state.dat (Windows 사용자 계정으로 암호화)
이전 검토용 설정은 별도 폴더이므로 공유 주소를 다시 등록하세요.
1.0.x의 웹 게시 주소는 다시 등록해야 하며, 기존 웹 게시도 Google에서 별도로 중지하세요.
위젯의 연결 해제는 Google 공유 권한을 바꾸지 않습니다.

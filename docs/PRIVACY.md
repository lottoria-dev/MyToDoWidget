# 개인정보와 연결정보

## 저장 위치

메모·일정은 먼저 사용자의 PC에 저장합니다. 연결 후에는 사용자가 직접 만든 개인 Google 시트와 그 시트에 연결된 Apps Script로 동기화합니다. MyToDo2의 메모 동기화는 개발자 서버를 거치지 않습니다.

개인 시트의 공유는 **제한됨**으로 유지하세요. 시트 전체를 웹에 게시할 필요가 없습니다.

개발자의 Google Drive 파일·템플릿 주소는 사용하지 않습니다. 프로그램에 내장된 공개 설치 코드를 본인의 빈 시트에서 실행합니다. 권한 승인·웹 앱 배포도 본인 계정에서 진행하며, Google의 계정·권한 관리 책임은 남습니다. 시트 연결 안내의 완료 단계는 PC에 저장되며, 브라우저 작업을 자동으로 검증했다는 뜻은 아닙니다.

## 전용 코드는 암호처럼 보관

전용 코드와 연결정보 파일에는 시트 접근에 필요한 정보가 들어 있습니다. 가진 사람은 메모를 읽거나 변경할 수 있으므로 공개 게시물·스크린샷·GitHub Issues에 넣지 마세요. 코드가 알아보기 어렵다고 암호화된 백업이 되는 것은 아닙니다.

노출되었다면 개인 시트의 **MyToDo2 → 연결 키 폐기** 후 새 연결정보를 만들어 각 PC에 다시 등록하세요. 기존 코드로 연결한 다른 PC도 다시 연결해야 합니다.

## 권한과 서비스 제한

처음 연결할 때 본인 계정으로 스크립트 실행 권한을 승인합니다. 코드는 연결된 시트를 처리하지만 Google 승인 화면의 스프레드시트 권한 범위는 그보다 넓게 표시될 수 있습니다. 자신의 프로젝트와 요청 권한을 확인하세요.

웹 앱은 Google 로그인 없이 위젯 요청을 받도록 배포하고 MyToDo2 연결 키로 요청을 확인합니다. 개인 시트의 **제한됨**과 웹 앱의 **모든 사용자**는 서로 다른 설정입니다. 정보 유출 위험을 완전히 없애는 구조는 아니므로 공용 PC 이용과 민감한 개인정보 입력은 신중히 결정하세요.

계정·조직 정책, Apps Script 실행 제한, 네트워크 상태에 따라 연결이 제한될 수 있습니다. 기본 정기 조회는 30분이며 수동 동기화도 가능합니다.

## 백업과 외부 서비스

- 구글 시트 연결정보는 JSON 백업에 포함하지 않습니다. 연결용 코드·파일은 따로 보관하세요.
- JSON·CSV 백업은 암호화되지 않습니다. 안전한 곳에 보관하세요.
- 외부 메모 서비스로 보내기는 본문 복사 후 웹사이트를 여는 기능입니다. 사용자가 직접 붙여넣습니다.
- 위젯에서 삭제해도 시트에는 보관으로 남습니다. 완전히 지우려면 시트와 별도 백업에 남은 내용도 확인해야 합니다.

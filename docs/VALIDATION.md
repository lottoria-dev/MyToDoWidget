# 0.3.0 검증 기록

## 이번에 확인한 범위

- C# 소스 17개를 Roslyn으로 구문 분석했습니다.
- 변경된 상태·모양 값·외형 전달 코드 3개는 .NET 10 참조 어셈블리로 형식도 분석했습니다. 어셈블리 출력(Emit)은 하지 않았습니다.
- XAML·프로젝트·빌드 속성·매니페스트 XML 8개를 파싱했습니다.
- XAML 리소스 18개와 메인 화면 이벤트 18종, 설정 화면 이벤트 12종의 연결을 확인했습니다.
- 상단 아이콘 6개, 상단 24 / 하단 20 높이 비율, 하단 한 줄 표시를 확인했습니다.
- 유리판·말풍선 배경의 0% 투명 / 100% 불투명 방향과 독립 적용, 글자색 별도 적용을 검토했습니다.
- 5가지 모양, 꼬리 3방향, 파스텔 12종, 사용자 색·글꼴 설정과 저장/취소 흐름을 검토했습니다.
- 롤업 시 펼친 높이를 보존하고, 롤다운·재실행 시 복원하는 흐름을 검토했습니다. 접힌 창의 화면 내 위치 판단도 작은 높이를 반영하도록 수정했습니다.
- 다른 시트로 바꾸면 접힌 상태에서 보관하던 스크롤 위치도 초기화하도록 확인했습니다.
- 말풍선 더블클릭과 상단 구글 시트 아이콘이 동일한 Google Sheets 목록 열기 함수를 사용합니다.
- 기존 저장 주소 비표시, CSV 순서·텍스트 보존, 보호 저장, 상태 스키마와 중복 실행 방지 이름을 유지했습니다.

사용자 요청에 따라 앱 빌드·게시·실행 파일 생성은 하지 않았습니다.
구문·일부 형식 분석과 XML 검사는 WPF 전체 빌드나 Windows 화면 실행 검증을 대체하지 않습니다.
기존 핵심 로직 검사 프로젝트는 포함했으며 이번 작업에서는 실행하지 않았습니다.

## Visual Studio와 Windows에서 확인할 항목

1. 이전 버전을 트레이에서 종료하고 솔루션을 Release로 빌드합니다. MyToDoWidget을 시작 프로젝트로 실행합니다.
2. 기존 연결·메모·위치·창 크기가 이어지는지, 유리판 비침 정도는 유지되고 표시 숫자만 새 방향으로 바뀌는지 확인합니다.
3. 새로고침 / 구글 시트 / 설정 / 롤업 / 롤다운 / 최소화 아이콘의 툴팁과 동작을 확인합니다. 말풍선 더블클릭은 Google Sheets 목록을 열어야 합니다.
4. 하단이 최근 정상 갱신 시각 한 줄만 표시하는지 확인합니다. 갱신 실패·설정 저장·메모 복사로 시각이 바뀌면 안 됩니다.
5. 5가지 모양 × 꼬리 왼쪽/오른쪽/없음을 비교합니다. 한 줄·여러 줄·화면보다 긴 글·공백 없는 문자열에서 글자가 모양 밖으로 나가면 안 됩니다.
6. 파스텔 12종을 선택하고 배경색/글자색을 직접 변경합니다. 유효하지 않은 HEX 입력으로는 저장되지 않아야 합니다.
7. 유리판과 말풍선 배경을 각각 0/50/100%로 바꿔 독립 적용을 확인합니다. 글씨는 별도로 선명하게 유지되어야 합니다. 모두 0%일 때에는 글자나 스크롤바 위에서 휠을 사용합니다.
8. 글꼴·크기 11/36·굵게·기울임을 바꿔 미리보기와 실제 위젯을 비교합니다. 설정 취소/X/ESC 시 원래대로 돌아와야 합니다.
9. 저장 후 종료·재실행하여 모양·꼬리·사용자 색·불투명도·글꼴을 확인합니다. 새 주소 확인에 실패하고 취소해도 이전 설정과 연결을 유지해야 합니다.
10. 중간 메모를 읽던 위치에서 롤업/롤다운하고 이전 높이·스크롤이 복원되는지 확인합니다. 롤업 후 종료·재실행·롤다운 시에도 펼친 높이가 보존되어야 합니다.
11. 접힌 상태에서 시트를 교체하고 펼치면 새 시트의 처음을 표시해야 합니다. 최소화 후 트레이 복원 시에는 접힘/펼침 상태가 유지되어야 합니다.
12. 긴 말풍선 휠 스크롤, 같은 내용 새로고침 시 읽던 위치 유지, 전체 메모 복사를 확인합니다.
13. 최소 창 너비 310, Windows 배율 100/125/150/200%, 보조 모니터 분리, 위치 잠금, 주 모니터로 가져오기를 확인합니다.
14. 인터넷 연결 실패 시 캐시 유지, 정상 빈 A열을 받으면 목록 비우기, 기존 주소가 설정창에서 드러나지 않는지 확인합니다.

이번 환경에는 Windows 데스크톱이 없어 WPF 화면·색상 선택창·설치 글꼴·실제 휠·DPI·DPAPI·트레이 동작을 실행 검증하지 못했습니다.
사용자의 실제 시트 주소가 제공되지 않았으므로 실제 Google Sheets 읽기는 검증하지 않았습니다.

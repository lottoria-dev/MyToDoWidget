# MyToDo2 사용법

## 메모와 일정

상단 **M/S 스위치**의 왼쪽 **M**은 메모, 오른쪽 **S**는 일정입니다. 짙은 회색 바탕과 흰 글자로 반전된 쪽이 현재 선택한 목록입니다. 마우스를 올리면 한글 이름과 미완료 수량을 확인합니다.

상단 **＋** 또는 `Ctrl+N`으로 추가합니다. 메모는 날짜 없이 본문만 자유롭게 적어도 됩니다. 일정은 날짜·제목을 먼저 보여 주므로 상담·출장·제출 기한을 정리하기에 좋습니다.

- **연필 / 더블클릭:** 편집
- **완료 버튼:** 완료·취소. 완료한 일정 제목에 삭제선 표시
- **휴지통:** 위젯에서 숨기고 연결된 시트에는 보관
- **항목 화살표:** 1줄 → 2줄 → 전체 보기
- **상단 롤업 버튼:** 위젯 전체 접기·펼치기
- **상단 최소화 버튼:** 트레이로 숨기기. 트레이 아이콘으로 다시 표시
- **마우스 휠 / ▲ ▼:** 내용 스크롤

설정, 구글 시트 열기, 본문 복사와 프로그램 종료는 **우클릭 메뉴**에 있습니다.

말풍선을 끌어 순서를 바꿀 수 있습니다. 파란 선이 놓일 위치입니다. 순서는 개인 시트에 저장하며, 같은 시트를 연결한 다른 PC도 동기화 후 같은 순서로 표시합니다. 우클릭의 **이 탭 기본 순서로 정렬**도 함께 반영됩니다.

높이는 항목 개수·접기/펼치기에 맞춰 자동 조절합니다. 화면 하단의 작업 영역을 넘는 내용은 스크롤합니다. 가로 폭은 직접 조절합니다.

## 날짜·태그·출처 입력

편집창 입력 보조에서 종류를 고르고 값만 넣은 뒤 **Enter** 또는 **넣기**를 누르면 본문에 기호가 붙습니다. 직접 입력해도 됩니다.

| 기호 | 의미 | 본문 입력 예시 |
|---|---|---|
| `#` | 검색용 태그 | `#수업 #준비` |
| 줄 처음의 `@` | 출처 | `@교무부` |
| 줄 처음의 `>` | 참고 링크 | `>https://example.com/` |
| `!날짜` | 일정 날짜 | `!날짜 2026-11-02` |
| `!시간` | 일정 시각 | `!시간 15:30` |

날짜·시각·출처·링크는 **각각 별도 줄의 처음**에 씁니다. 일반 문장의 날짜를 임의로 변환하지 않으며 이메일 속 `@`는 그대로 둡니다. 편집창 날짜·시각 표시는 본문에서 읽은 결과입니다. 날짜는 본문의 `!날짜`, `!시간`에서 바꾸세요. 날짜만 쓰면 종일 일정입니다.

**표시할 날짜·시각과 알림 시각은 별개**입니다. 알림은 편집창에서 따로 지정하세요.

제목을 **학생 상담**으로 정하고 본문을 아래처럼 적어 보세요.

```text
장소: 상담실
준비: 상담 기록과 학습 계획표
!날짜 2026-11-02
!시간 15:30
#상담 #학교
@담임
```

처음 설치할 때 준비되는 상담·출장·보고서 마감 예시는 내용과 날짜만 바꿔 사용할 수 있습니다. 예시의 알림은 꺼져 있습니다.

## 찾기와 꾸미기

상단 **돋보기 / Ctrl+F / 우클릭 → 검색 / 완료 항목 보기**로 검색창을 엽니다. 검색에 단어 또는 `#태그`를 넣습니다. 여러 단어·태그는 **모두 포함하는 항목**을 찾습니다. 항목의 태그를 눌러 검색할 수도 있습니다. 완료 항목이 안 보이면 검색 영역의 **완료** 표시를 확인하세요.

폭을 좁히면 일부 상단 보조 버튼이 접힙니다. **Ctrl+N**으로 추가, **F5**로 동기화, **Ctrl+F**로 검색하고 마우스 휠로 스크롤할 수 있습니다. M/S와 전체 접기·최소화는 계속 표시됩니다.

**우클릭 → 설정**에서 말풍선 모양·꼬리·간격·배경색·태그색·글꼴을 조절합니다. 항목별 배경색은 각 편집창에서 선택합니다. 유리판, 상단바, 흰색 테두리의 불투명도도 따로 조절합니다. **0%는 완전 투명, 100%는 완전 불투명**입니다.

임박한 미완료 일정은 지정한 배경색으로 강조할 수 있습니다. 완료하거나 강조 기간을 벗어나면 항목별 색상으로 돌아갑니다.

## 저장과 동기화

연결 전에는 이 PC에 저장합니다. 연결 후에는 편집 저장·완료·삭제·순서 변경 시 변경사항을 자동으로 전송합니다. 실패한 변경은 PC에 남으므로 연결 상태를 확인한 뒤 다시 동기화하세요.

프로그램을 실행하면 연결된 시트를 1회 동기화합니다. 수동 모드에서도 첫 요청은 실행합니다. 다른 PC·시트의 변경은 기본 **30분마다** 확인합니다. **설정 → 동작 → 정기 동기화 간격**에서 바꿉니다. 수동 모드는 정기 조회를 끄며 편집 저장 후 전송은 유지합니다. 즉시 확인은 **↻ / F5 / 우클릭 → 지금 동기화**입니다.

PC를 옮기기 전에는 동기화 결과를 확인하세요. 다른 PC에도 같은 전용 코드를 등록합니다.

## 삭제한 내용 다시 보기

휴지통 버튼은 연결된 시트의 원문을 지우지 않습니다. 시트에서 해당 행의 **위젯 표시**를 **보관 → 표시**로 바꾸고 동기화하면 복원됩니다. 시트의 행 자체를 삭제하는 동작과는 다릅니다.

## 백업

**우클릭 → 메모 백업 / 가져오기** 또는 **설정 → 백업**을 엽니다.

- **JSON 백업 저장:** 로컬 PC에 데이터 백업(위젯 설정 유지)
- **JSON 백업 가져오기:** 로컬 PC 데이터 불러오기
- **CSV 저장:** 엑셀 등의 도구로 열어볼 수 있도록 변환

- **구글 시트 연결정보는 백업하지 않음**
- **백업 파일은 암호화되지 않으므로 안전한 곳에 보관**

JSON 가져오기는 기존 내용을 보존하며 데이터를 추가하고 백업에 포함된 위젯 설정을 복원합니다. 동일한 내용은 중복을 피합니다. 창 위치·크기와 Windows 자동 실행 등록은 현재 PC 설정을 유지합니다. 전용 코드·연결정보 파일은 별도로 보관하세요.

## 다른 메모 서비스에 붙여넣기

**설정 → 동작 → 본문을 붙여넣을 앱**에서 Google Keep, OneNote, iCloud 메모, Notion 중 하나를 고릅니다.

항목 우클릭 → **메모 복사 · 선택한 서비스 열기**로 전체 본문을 복사하고 웹사이트를 엽니다. 로그인 후 원하는 메모에 **Ctrl+V**로 붙여넣으세요. 자동 동기화나 자동 붙여넣기는 아닙니다.

## Windows 시작 시 실행

**설정 → 동작 → Windows 시작 시 자동 실행**을 켜고 저장합니다. 실행 폴더를 옮겼다면 새 위치에서 한 번 실행하세요. Windows 시작 앱에서 차단했다면 그곳에서도 사용으로 바꿔야 합니다.

# 처음 연결하기

**위젯 우클릭 → 설정 → 시트 연결 → 처음 설정해요**를 선택합니다. 현재 단계만 펼쳐지고, 완료 버튼을 누르면 다음 단계가 열립니다. 창을 닫아도 완료한 단계는 이 PC에 저장됩니다.

## 1. 내 시트 만들기

- **위젯:** 새 시트 만들기
- **브라우저:** 본인 Google 계정으로 로그인하고 빈 시트가 열리는지 확인
- **위젯:** 시트가 열렸어요 → 다음

개발자의 시트를 복사하지 않습니다. 새 시트 이름은 자유롭게 바꾸어도 됩니다.

## 2. 설치 코드 붙여넣기 · 실행

- **위젯:** 설치 코드 복사
- **시트 상단:** 확장 프로그램 → Apps Script
- **편집기 왼쪽:** Code.gs 선택 → Ctrl+A → Ctrl+V → Ctrl+S
- **편집기 상단 함수 목록:** setupMyToDo 선택 → 실행
- **Google 승인 화면:** 권한 검토 → 본인 계정 → 요청 권한 확인 후 허용
- **시트로 돌아오기:** 상단에 MyToDo2 메뉴가 보이는지 확인
- **위젯:** MyToDo2 메뉴가 보여요 → 다음

복사·붙여넣기는 한 번입니다. HTML 파일 추가나 appsscript.json 수정은 필요하지 않습니다. 시트 형식·자유 메모 2개·일정 3개·연결 화면을 함께 준비합니다.

메뉴가 안 보이면 시트를 새로고침하세요. ‘확인되지 않은 앱’ 화면에서는 방금 본인이 만든 프로젝트인지 먼저 확인합니다. 본인 프로젝트이고 진행 항목이 제공된다면 **고급 → 프로젝트로 이동 → 허용** 순서로 진행합니다. ‘차단됨’으로 진행할 수 없다면 우회하지 말고 계정·조직 정책을 확인하세요.

## 3. 웹 앱 배포

- **Apps Script 오른쪽 위:** 배포 → 새 배포
- **유형 선택(톱니바퀴):** 웹 앱
- **실행 사용자:** 나
- **액세스 권한:** 모든 사용자
- **배포:** 승인이 나오면 본인 계정으로 확인
- **완료 창:** 웹 앱 → URL → 복사
- **위젯:** 웹 앱 URL을 복사했어요 → 다음

복사할 것은 **끝이 /exec인 웹 앱 URL**입니다. 배포 ID나 /dev 테스트 주소가 아닙니다. 시트 자체의 공유는 **제한됨**으로 유지하세요. 학교·회사 계정에서 ‘모든 사용자’를 선택할 수 없다면 조직 정책을 확인해야 합니다.

## 4. 전용 코드 만들고 연결

- **시트 상단:** MyToDo2 → 위젯 연결
- **연결 창:** 웹 앱 URL 붙여넣기 → 전용 코드 만들기 → 전용 코드 복사
- **위젯:** 코드 붙여넣기 → 연결하기

올바른 코드 형식이면 연결하기 버튼이 켜집니다. 버튼을 누르면 위젯이 실제 접속을 확인합니다. 연결 전 이 PC에 적은 메모도 연결 후 전송됩니다.

**다른 PC:** ‘전용 코드가 있어요’를 선택하고 같은 코드를 붙여넣어 연결합니다. 새 시트·새 배포는 필요하지 않습니다. 전용 코드는 암호처럼 보관하세요. ‘안내 처음부터’는 안내 진행만 초기화하며 메모·연결정보는 지우지 않습니다.

## 연결 후

- 편집 저장 후 변경사항을 전송합니다.
- 다른 PC의 변경은 기본 30분마다 확인합니다.
- 지금 확인: F5 / 우클릭 → 지금 동기화
- 설정 변경: 설정 → 동작 → 정기 동기화 간격

Google 공식 참고: [권한 승인](https://developers.google.com/apps-script/guides/services/authorization), [웹 앱 배포](https://developers.google.com/apps-script/guides/web).

# 연결과 데이터 보관 — 1.1.2

MyToDo 1.x는 Google Sheets의 ‘링크가 있는 모든 사용자 · 뷰어’ 설정을 사용합니다.

**민감한 메모는 입력하지 않는 것을 권장합니다. 뷰어는 수정을 막지만, 링크를 아는 사람은 로그인 없이 내용을 읽을 수 있습니다.**

학생·다른 사람의 개인정보, 비밀번호, 계정 인증 정보 등은 입력하지 마세요.
공유 파일에서 소유자의 이름·이메일도 표시될 수 있습니다.
공유 권한은 파일 전체에 적용됩니다. 위젯에서 A열만 표시해도 다른 열·탭의 접근 권한이 제한되지는 않습니다.
메모 전용 스프레드시트 파일을 사용하는 편이 좋습니다.

## 읽기 동작

- 일반 공유 주소 또는 메모 탭을 연 브라우저 주소를 받습니다. 선택한 탭의 CSV를 다운로드하고 A열만 표시합니다.
- 탭 번호가 없는 주소는 첫 탭을 읽습니다. ‘웹에 게시’ 주소로 새 연결을 만들지는 않습니다.
- HTTPS GET 요청만 사용합니다. 시트를 수정·업로드하지 않습니다.
- Google 로그인 정보, 브라우저 쿠키, OAuth 토큰을 사용하거나 수집하지 않습니다.
- 다운로드 리다이렉트는 HTTPS Google 문서 / Googleusercontent 대상으로 제한합니다.
- 로그인 페이지, HTML·스크립트 응답, 과도한 응답은 거부합니다. 실패하면 마지막 정상 메모를 유지합니다.
- 입력된 주소의 파일 ID·탭 번호·리소스키 외의 쿼리 매개변수는 전달하지 않습니다.
- URL, 메모, 서버 오류 본문을 진단 로그에 기록하는 기능을 넣지 않습니다.

## 로컬 저장

- 선택적 검토용: `%LOCALAPPDATA%\MyToDoWidget.Test\state.dat`
- 기본 정식판: `%LOCALAPPDATA%\MyToDoWidget\state.dat`
- 연결 주소, 마지막 메모, 갱신 시각과 외형 설정을 Windows DPAPI CurrentUser로 암호화합니다.
- 정상 저장 시 백업을 유지합니다. 연결 교체·해제 시 기존 연결의 백업을 지웁니다.
- 설정에는 주소의 등록 여부만 보여 줍니다. 저장된 주소 조회·복사·내보내기를 제공하지 않습니다.
- 구글 시트 열기는 항상 https://docs.google.com/spreadsheets/ 목록을 엽니다.
- 같은 Windows 계정으로 실행하는 다른 프로그램까지 접근을 막는 기능은 아닙니다.
- 로컬 암호화·주소 숨김은 Google의 공유 권한과 링크 유출 위험을 바꾸지 않습니다.

## 연결 해제와 이전 버전

- 위젯의 연결 해제는 로컬 연결과 캐시만 지웁니다. Google의 공유 권한은 바꾸지 않습니다.
- Google에서 접근을 막으려면 일반 액세스를 ‘제한됨’으로 변경하세요.
- 예전에 ‘웹에 게시’를 썼다면 게시 중지도 별도로 해야 합니다.
- 정식 설정을 사용하는 빌드가 1.0.x의 게시 주소를 발견하면 외형은 유지하고 연결·캐시를 해제한 뒤 일반 공유 주소 등록을 안내합니다.
- 선택적 검토용 빌드는 정식판 설정을 가져오지 않습니다. 정식판도 검토용 폴더를 가져오지 않으므로 공유 주소를 다시 등록하세요.

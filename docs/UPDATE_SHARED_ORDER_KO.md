# 기존 시트 스크립트 갱신

통신 규격 3의 기존 시트는 같은 전용 코드로 사용할 수 있습니다. 설치 방식을 바꾸기 위해 기존 데이터를 초기화할 필요는 없습니다.

1. 개인 시트의 확장 프로그램 → Apps Script → 기존 서버 코드 전체를 apps-script/MyToDoSetup.gs로 교체하고 저장합니다. 위젯의 ‘설치 코드 복사’ 내용도 같습니다.
2. HTML 파일 추가나 appsscript.json 교체는 하지 않습니다. 예전 Setup.html은 더 이상 사용하지 않습니다.
3. 함수 목록에서 setupMyToDo를 실행합니다. 기존 메모·키·순서를 보존하며 안내와 메뉴를 갱신합니다.
4. 배포 → 배포 관리 → 기존 웹 앱 수정(연필) → 버전: 새 버전 → 배포합니다.
5. 각 PC에서 F5로 동기화합니다.

기존 배포 URL·연결 키·전용 코드를 유지합니다. 사용 중인 시트에서 예전 prepareMyToDoTemplate을 실행하지 마세요. 갱신 전 시트와 로컬 데이터를 백업해 두세요.

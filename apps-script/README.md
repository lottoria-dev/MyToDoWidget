# MyToDo2 단일 설치 스크립트

일반 사용자는 **위젯 우클릭 → 설정 → 시트 연결**의 순서대로 진행합니다. 위젯의 ‘설치 코드 복사’는 이 폴더의 **MyToDoSetup.gs 전체 내용**을 복사합니다. 설치용 별도 실행 파일은 없습니다.

1. 본인 계정에서 새 빈 Google 시트를 만듭니다.
2. 확장 프로그램 → Apps Script → Code.gs의 전체 내용을 MyToDoSetup.gs로 교체하고 저장합니다.
3. 함수 목록에서 setupMyToDo를 실행하고 본인 계정으로 권한을 승인합니다.
4. 배포 → 새 배포 → 웹 앱에서 실행 사용자 ‘나’, 액세스 ‘모든 사용자’로 배포하고 웹 앱 URL을 복사합니다.
5. 시트의 MyToDo2 → 위젯 연결에서 URL을 넣고 전용 코드를 만들어 위젯에 등록합니다.

자세한 버튼 위치는 [처음 연결하기](../docs/APPS_SCRIPT_SETUP_KO.md)를 확인하세요. **HTML 파일 추가·매니페스트 교체·개발자 원본 시트 주소가 필요하지 않습니다.**

## 생성 내용과 보존

설치 코드는 데이터·관리 시트와 시작 안내, 자유 메모 2개·일정 3개를 준비합니다. 기본 시트1은 사용하지 않으므로 삭제해도 됩니다. MyToDo와 관리 시트의 이름·내부 열은 유지하세요. setupMyToDo를 다시 실행해도 기존 메모·연결 키·공유 순서를 지우지 않고 예시를 중복 추가하지 않습니다.

시트 공유는 제한됨으로 유지합니다. 웹 앱은 전용 연결 키로 요청을 확인합니다. 코드를 가진 사람은 메모를 읽거나 바꿀 수 있으므로 전용 코드를 공개하지 마세요.

## 기존 시트 갱신

통신 규격은 3입니다. [기존 시트 갱신](../docs/UPDATE_SHARED_ORDER_KO.md)을 따르세요. MyToDoSetup.gs에는 연결 화면이 포함되어 있습니다. 옛 Setup.html은 새 코드에서 참조하지 않습니다.
